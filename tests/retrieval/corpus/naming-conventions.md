Naming conventions for the sample warehouse. Use the column name that is already in the table. Booked revenue is revenue_usd, not sales_amount and not gmv. Daily active users are dau. New users are new_users. Event date is event_date, written as an ISO date. Product values are Atlas, Northstar, and Harbor. Region values are AMER, EMEA, and APAC. Channel values are direct, partner, and self-serve. Platform values are ios, android, and web.

A campaign name, a cost center, and a person's name are not columns. Do not abbreviate EMEA to EU in a query even if a source system rename is one of the known issues. Write the rename in the note beside the chart instead of inventing a third region code. Shared notes use these names so finance and growth are talking about the same extract. Role glossaries may add a definition, but they should not invent a synonym that contradicts this list.
