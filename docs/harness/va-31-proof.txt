Before -> after
Before: DB path came only from the environment. Every uploaded text file was retrieved. PDF/xlsx/png were refused.
After: an enabled Connections row replaces the environment SQLite path until Disable. New uploads are draft and are not retrieved. Existing rows are approved. PDF/xlsx/png are stored and skipped.

How to enable a SQLite connection
1. python -m src.operator_secret --init
   (once; the owner signs in with that secret)
2. streamlit run app.py
3. Sign in as owner. Open Connections.
4. SQLite file path: a local file, for example data/demo.db
5. Type the operator secret again. Test connection. Then Enable.
6. Sign in as a role that can query. Ask a revenue question. The rows come from that file.
7. Connections -> operator secret -> Disable. The next ask uses DB_PATH again.

How to upload md/csv and approve or reject
1. Sign in as analyst (password analyst on the demo file). Open 知識庫.
2. Upload a .md or .csv (2 MB or smaller). The card says Approval · draft.
   There is no Approve button.
3. Sign out. Sign in as owner. Open 知識庫. The same file is listed.
4. Approve. The card says Approval · approved.
5. Reject. The card says Approval · rejected.

How to prove a draft is excluded from retrieval
The live path is store.search / store.prompt_notes, which answer_question uses when a model key is set.
The local planner does not read notes, so the UI demo without a key cannot show the exclusion.
Run:

  python3 -m pytest -q tests/test_knowledge_approval.py::test_new_uploads_are_draft_and_live_retrieval_is_approved_only

That test uploads a glossary, asserts search is empty, asserts the model prompt does not contain the filename, approves, asserts a hit, rejects, asserts search is empty.

Security invariants
- Test does not open a refused target. Messages and audit rows do not contain the submitted URL.
- No database password is written to the connections table, the page, the audit log, or export.
- The SQLite path is not a secret, so it is not Fernet-encrypted. Mail passwords still are.
- Test, Enable, and Disable ask for the operator secret again and then drop it from the session.
- PDF/xlsx bytes are not chunked and the search query also excludes those extensions.
- Approved memory does not change table grants, routing.yaml, or the SELECT allowlist.
