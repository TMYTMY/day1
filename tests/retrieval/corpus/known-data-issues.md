Shared list of data issues a new analyst should expect in the demo warehouse. The revenue extract has duplicate grain keys, a late Harbor backfill, null partner channels, a region rename from EMEA to E.U., and a stretch of euro list prices stored in revenue_usd. The dau extract will double count a person who uses two platforms because there is no identity key. These are planted so the demo is not a perfect table. They are not an invitation to hide rows.

Read the finance known-issues note before quoting revenue, and the growth known-issues note before quoting daily active users. The refresh runbook explains how a backfill lands. The naming note explains which codes are valid. If a defect is outside this list, stop and ask. Do not patch the warehouse from a local file. Write the limitation next to the number, including the column and the date span you actually queried. This note is shared. It does not grant access to a table your role cannot query.
